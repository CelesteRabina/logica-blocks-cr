¿Cómo funciona?

📥 LEER

Pide al usuario que ingrese un dato y lo guarda en una variable.
Ej: variable nombre → el usuario escribe "María"

📤 ESCRIBIR

Muestra un mensaje o el valor de una variable.
Usá {nombre} para mostrar el contenido de una variable.
Ej: Hola, {nombre}!

🔢 ASIGNAR

Guarda un cálculo o valor en una variable.
Podés hacer sumas, restas, multiplicaciones y divisiones.
Ej: variable total = {precio} * {cantidad}

🔀 SI / SINO

Toma una decisión según una condición.
Usá > < = para comparar.
Ej: SI {edad} >= 18 → ENTONCES escribir "Sos mayor de edad"

🔄 REPETIR

Repite una acción N veces.
Usá {i} para indicar el número de repetición actual.
Ej: 3 veces → {i} x 5 = {i*5}

💡 Tip: Usá {variable} para insertar el valor de cualquier variable en un texto o cálculo.
